# Exercise 01
(Easy) Create a 2x2 RGB uint8 array with four distinct colors. 
Convert HWC to CHW and back, print both shapes, and prove the round trip preserves every value.

========================================================

# 1. Khởi tạo mảng 2x2 RGB kiểu uint8 với 4 màu khác biệt
INITIALIZE original_img AS numpy array of shape (2, 2, 3) WITH dtype=uint8
# Ví dụ 4 màu: Đỏ [255, 0, 0], Xanh lá [0, 255, 0], Xanh dương [0, 0, 255], Vàng [255, 255, 0]

# 2. Hàm chuyển đổi trục
FUNCTION hwc_to_chw(img):
    TRANSPOSE img axes FROM (0, 1, 2) TO (2, 0, 1)
    RETURN transposed_img

FUNCTION chw_to_hwc(img):
    TRANSPOSE img axes FROM (0, 1, 2) TO (1, 2, 0)
    RETURN transposed_img

# 3. Thực thi chuyển đổi vòng tròn (round trip)
chw_img = hwc_to_chw(original_img)
recovered_img = chw_to_hwc(chw_img)

# 4. In kích thước (shape)
PRINT "HWC shape:", original_img.shape      # Kết quả mong đợi: (2, 2, 3)
PRINT "CHW shape:", chw_img.shape           # Kết quả mong đợi: (3, 2, 2)

# 5. Chứng minh bảo toàn giá trị (round trip preserves every value)
ASSERT ALL ELEMENTS EQUAL: original_img == recovered_img
PRINT "Roundtrip preserved:", array_equals(original_img, recovered_img)
